# Ahmed Guudle — Portfolio Website

A complete responsive portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design and animations
- `script.js` — mobile menu, dark/light mode, reveal animations and contact form

## Customize
1. Open `index.html`.
2. Replace the name, bio, project descriptions, social links and email.
3. In `script.js`, replace `your.email@example.com` with your real email.
4. Upload all three files to GitHub Pages, Netlify, Vercel, or another static host.

## GitHub Pages
Create a repository, upload the three files to the root, then open:
Settings → Pages → Deploy from branch → main → /(root).

No build step is required.
